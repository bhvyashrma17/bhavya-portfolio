Process

How one of these campaigns gets made, from the first message to files a client can post.

  1. Brief

    One sentence the client agrees with, a goal we can check, and the list of deliverables with their sizes.

  2. System

    Palette, type and two or three repeatable devices per brand: Mettle's knurled texture, Dabara's steel tumblers, Barsaati's rain lines.

  3. Templates

    Each format is built once at exact pixel size with live text, so next week's post takes minutes, not hours.

  4. Export

    Stills as 1080-wide images, motion rendered frame by frame and encoded as MP4, all named by date and format.
